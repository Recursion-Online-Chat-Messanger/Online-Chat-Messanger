# Online-Chat-Messanger
自分のチャットルームを作って、誰とでもすぐにつながれるメッセンジャーシステム

クライアントが自分専用のチャットルームを作成し、
他のクライアントとリアルタイムで会話できるチャットシステムです。  
ホストはルームを作成でき、ゲストは既存のルームに参加して自由に会話できます。  
また、どのクライアントも任意のタイミングで退出が可能です。  
**ただし、ホストが退出した場合はルーム自体が削除されます。**  

## 使用言語
- Python

## 特徴
- CLI(コマンドライン)を使ってやり取りできる
- TCP/UDPを用いたリアルタイム通信

## 前提条件
- Gitがインストールされている
- Python3.0以上がインストールされている

## 使用方法
### 1\. リポジトリをクローン  
``` git clone https://github.com/Recursion-Online-Chat-Messanger/Online-Chat-Messanger.git ```  
``` cd Online-Chat-Messanger ```

### 2\. サーバーを起動  
``` python3 main.py server ```  
※ Windows の場合は```python```でも可

### 3\. クライアントを起動  
``` python3 main.py client ```  
※ Windows の場合は```python```でも可

### 4\. ルームを作成(ホストクライアント)  
4\.1 ルーム名を入力  
``` Room name: <作成したいルーム名> ```  
4\.2 ユーザー名を入力  
``` Username: <自身のユーザー名> ```  
4\.3 「作成する(1)」を選択する  
``` Choose number -- 1(create) or 2(join): 1 ```  

### 5\. ルームに参加する(ゲスト)  
5\.1 クライアントを起動する  
→ 手順「3. クライアントを起動」を参照  
5\.2 ルーム名を入力  
``` Room name: <参加したいルーム名> ```    
5\.3 ユーザー名を入力  
``` Username: <自身のユーザー名> ```    
5\.4 「ルームに参加する(2)」を選択する  
``` Choose number -- 1(create) or 2(join): 2 ```   

### 6\. メッセージを送信(ホスト・ゲスト共通)    
``` > <送信したいメッセージ> ```  

### 7\. メッセージ確認(ホスト・ゲスト共通)  
``` [送信先のユーザー名] <メッセージ> ```  

### 8\. ルームを退出(ゲスト)  
8\.1 退出コマンド(exit)を入力   
``` > exit ```  

### 9\. ルームを退出(ホストクライアント)  
9\.1 退出コマンド(exit)を入力  
``` > exit ```  
9\.2 ルーム削除の確認に「yes」を入力  
``` You are the HOST. Closing room will disconnect all users. Continue? (yes/no): yes```  
※ no の場合  
``` Exit cancelled.``` 
が表示され、メールを送信が継続可能

### 10\.サーバーを停止  
``` Ctrl + C ```  

## テスト
サーバープログラム起動からクライアントプログラムを起動し、ユーザー（ホスト・ゲスト）のルーム退出までの一連の動作確認に使用したコマンド・入力内容を、以下にまとめていきます。
また、事前にサーバー、ホストクライアント、ゲスト1、ゲスト2の4つのターミナルを起動して、動作確認をしております。

### 2\. ホストクライアント起動

### 3\. ゲスト1起動 
`python3 main.py client`

### 4\. ゲスト2起動 
`python3 main.py client`: 

### 5\. ホストの入力

``` Room name: <作成したいルーム名> ```  
5\.2 ユーザー名を入力  
``` Username: <自身のユーザー名> ```  
5\.3 「作成する(1)」を選択  
``` Choose number -- 1(create) or 2(join): 1 ```  

### 6\. ゲスト1の入力
6\.1 ルーム名を入力  
``` Room name: <ホストが作成したルーム名> ```    
6\.2 ユーザー名を入力  
``` Username: <自身のユーザー名> ```    
6\.3 「ルームに参加する(2)」を選択する  
``` Choose number -- 1(create) or 2(join): 2 ```  

### 7\. ゲスト2の入力
7\.1 ルーム名を入力  
``` Room name: <ホストが作成したルーム名> ```    
7\.2 ユーザー名を入力  
``` Username: <自身のユーザー名> ```    
7\.3 「ルームに参加する(2)」を選択する  
``` Choose number -- 1(create) or 2(join): 2 ```  

### 8\. ホストからメッセージ送信
例:  
``` > Hello everyone! ```

### 9\. ゲスト1・ゲスト2がメッセージ受信
例:  
``` > [host] Hello everyone! ```
※手順8\.で送信されたメッセージをCLIで受信しているか確認

### 10\. ゲスト1がメッセージ送信
例:  
``` > Hello! ```

### 11\. ホスト・ゲスト2がメッセージ受信
例:  
``` [guest1] Hello! ```
※手順10\.で送信されたメッセージをCLIで受信しているか確認

### 12\. ゲスト2がメッセージを送信
例:  
``` > Hey guys! ```

### 13\. ホスト・ゲスト1がメッセージ確認
例:  
``` [guest2] Hey guys! ```
※手順12\.で送信されたメッセージをCLIで受信しているか確認

### 14\. ゲスト1によるルーム退出  
` > exit` 

### 15\. ホストによるルーム退出
``` > exit ```  
```  - (HOST) Exiting will close the room for everyone all users. Continue? (yes/no): yes ```

### 16\. ゲスト2によるルーム終了確認  
16\.1 Enter 押下でルーム退出

### 17\. サーバープログラム終了
`ctrl + c`
